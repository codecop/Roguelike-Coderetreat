# 2D Action-Adventure Game: Project Instructions

## Project Overview
We are building a **distributed 2D Action Adventure game** (Dungeon Crawler).

### Core Features
- Dungeon contains rooms with grid-based movement (up, right, down, left).
- Rooms have walls and at least one door to exit.
- Room size and complexity can vary.
- Dungeons may include traps, puzzles, and environmental hazards (e.g., hidden pitfalls, locked doors, pressure plates).
- Dungeons are inhabited by monsters and enemies that players must work around or defeat.

### Development Approach
- **Test-driven development (TDD)**: All features and changes should be implemented with corresponding tests.
- Work on one requirement/task at a time. Do not work ahead; note down ideas for future tasks.

## Workflow
1. Receive specific requirements for each task.
2. Write tests for the requirement before implementation.
3. Implement the feature/code to pass the tests.
4. Refactor and document as needed.
5. Repeat for each new requirement.
